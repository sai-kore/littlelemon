## How to Run this

1. Clone the repo:
git clone https://github.com/sai-kore/littlelemon.git

2. Go into folder:
cd littlelemon

3. Install dependencies:
pip install django djangorestframework

4. Run migrations:
python manage.py migrate

5. Start server:
python manage.py runserver

6. Open in browser:
http://127.0.0.1:8000/


| Page   | URL                                   |
| ------ | --------------------------------------|
| Home   | http://127.0.0.1:8000/                       
| Menu   | http://127.0.0.1:8000/menu/             
| Detail | http://127.0.0.1:8000/menu/1/         
| API    | http://127.0.0.1:8000/menu-items/ 
| Admin  | http://127.0.0.1:8000/admin/
